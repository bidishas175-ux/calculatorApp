#  Simple Calculator

A responsive web-based calculator built using HTML, CSS, and JavaScript that supports real-time arithmetic evaluation with both button and keyboard input.

---

##  Features
-  Basic arithmetic operations: Addition, Subtraction, Multiplication, Division
-  Supports parentheses `(` `)` for complex expressions
-  Full keyboard input support
-  Interactive button-based UI
-  Clear display (C button)
-  Delete last character functionality
-  Real-time expression display
-  Expression evaluation using JavaScript `eval()`
-  Error handling for invalid or undefined operations (e.g., divide by zero)

---

##  Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla JS)
